### مارکت های فعال

در ابتدا برای شروع به معامله در اسپات ، باید بدانیم که چه بازارهایی در این نوع معامله فعال هستند با استفاده از API زیر میتوانید لیست تمامی مارکت ها را مشاهده کنید.

```
GET /hector/web/v1/markets
```
