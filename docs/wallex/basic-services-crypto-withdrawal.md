### برداشت رمزارز با API Key

برای فراخوانی درخواست‌های این بخش، کلید API را در هدر `x-api-key` با قالب `<id>|<key>` ارسال کنید. سطح دسترسی و حداقل سطح کاربری هر درخواست در بخش مربوط به آن آمده است. برای ساخت کلید، [راهنمای ساخت API Key](./create-api-key.md) را ببینید.

### ثبت درخواست برداشت

```
POST /v1/account/crypto-withdrawal
```

این درخواست به سطح دسترسی `GENERAL` و `WITHDRAWAL` و سطح کاربری پیشرفته نیاز دارد. هنگام استفاده از API Key نیازی به OTP نیست. محدودیت نرخ آن ۶ درخواست در دقیقه است.

درخواست باید با هدر `Content-Type: application/json` ارسال شود.

| پارامتر | نوع | الزامی | توضیح |
| --- | --- | --- | --- |
| `coin` | رشته | بله | نماد رمزارز، مانند `USDT` |
| `network` | رشته | بله | نام شبکه؛ از `GET /v1/networks` یا `GET /v1/currencies` قابل بررسی است |
| `value` | رشته | بله | مقدار برداشت؛ باید بزرگ‌تر از صفر باشد. نمونهٔ مجموعهٔ ارسالی مقدار را به‌شکل رشته نشان می‌دهد |
| `wallet_address` | رشته | بله | آدرس کیف‌پول مقصد |
| `memo` | رشته یا `null` | خیر | ممو یا تگ مقصد برای شبکه‌هایی که به آن نیاز دارند |
| `client_unique_id` | رشته یا `null` | خیر | شناسهٔ دلخواه برای جلوگیری از ثبت درخواست برداشت تکراری |

نمونهٔ بدنهٔ درخواست (آدرس مقصد نمونه است و باید با آدرس واقعی جایگزین شود):

```
{
  "coin": "USDT",
  "network": "TRC20",
  "value": "10",
  "wallet_address": "T...",
  "memo": null,
  "client_unique_id": "my-unique-id-001"
}
```

`client_unique_id` اختیاری است و می‌تواند `null` باشد. اگر می‌خواهید از ثبت دو درخواست برداشت تکراری جلوگیری کنید، هنگام ساخت درخواست برای آن مقدار مشخصی بفرستید. اگر همان کاربر در درخواست دیگری همان مقدار را بفرستد، همان برداشت قبلی برگردانده می‌شود.

درخواست‌هایی که از IP ایران یا IP خصوصی ارسال شوند رد می‌شوند. اگر برای کلید API فهرست IP مجاز تعریف کرده‌اید، فقط درخواست‌های ارسالی از همان IPها پذیرفته می‌شوند.

> **محدودیت برداشت پس از تغییر اطلاعات امنیتی**
>
> تا ۲۴ ساعت پس از تغییر رمز عبور یا تغییر روش ورود دومرحله‌ای، درخواست برداشت حتی با API Key پذیرفته نمی‌شود.

### دریافت فهرست برداشت‌ها

```
GET /v1/account/crypto-withdrawal
```

این درخواست به سطح دسترسی `GENERAL` و سطح کاربری پایه نیاز دارد و فهرست برداشت‌های کاربر را به‌صورت صفحه‌بندی‌شده برمی‌گرداند. وضعیت‌های نمایش‌داده‌شده در پاسخ فهرست شامل `Accomplished`، `InProgress` و `Rejected` هستند. همهٔ پارامترهای زیر اختیاری‌اند.

| پارامتر | توضیح |
| --- | --- |
| `asset` | نماد رمزارز، مانند `USDT` |
| `wallet_address` | آدرس کیف‌پول مقصد |
| `memo` | ممو یا تگ مقصد |
| `network_id` | شناسهٔ شبکه |
| `from_date` | شروع بازه با قالب `YYYY-MM-DDTHH:mm:ssZ` |
| `to_date` | پایان بازه با قالب `YYYY-MM-DDTHH:mm:ssZ` |
| `per_page` | تعداد نتیجه در هر صفحه؛ حداکثر ۲۰ |
| `page` | شمارهٔ صفحه |

### دریافت جزئیات یک برداشت

```
GET /v1/account/crypto-withdrawal/{withdrawal_id}
```

`withdrawal_id` شناسهٔ برداشت در مسیر درخواست است. این درخواست به سطح دسترسی `GENERAL` و سطح کاربری پیشرفته نیاز دارد. اگر برداشت متعلق به کاربر نباشد، مقدار `result` خالی برمی‌گردد.

### اطلاعات شبکه و رمزارز

برای بررسی نام شبکه، کارمزد و حداقل مقدار برداشت می‌توانید از `GET /v1/networks` و `GET /v1/currencies` استفاده کنید. این دو آدرس عمومی‌اند و به احراز هویت نیاز ندارند.
